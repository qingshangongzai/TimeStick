# TimeStick（时间贴）

全屏时间悬浮窗 —— 极轻量级 Windows 桌面常驻工具。检测到前台应用进入全屏（游戏/观影）时，
自动在屏幕右下角弹出半透明时间悬浮窗；退出全屏立即隐藏。支持拖动、固定（鼠标穿透）与关闭。

## 构建

要求：Rust 1.85+（MSVC 工具链）、Windows 10/11 x64。

```bash
cargo build --release
```

产物：`target/release/timestick.exe`（约 150KB，无任何第三方运行时依赖）。

## 使用

双击 `timestick.exe` 即可（建议创建桌面快捷方式）。启动后静默驻留系统托盘，无主界面。

| 操作 | 说明 |
|---|---|
| 进入全屏 | 约 1.5 秒后悬浮窗出现在屏幕右下角（仅主显示器） |
| 悬浮窗外观 | 单行紧凑布局：`[时间] [图钉] [关闭]`，8px 圆角半透明背景，字号 18px |
| 自动反色 | 采样窗口上方背景亮度：浅色背景（白色网页/文档）自动黑字白底，深色背景白字黑底 |
| 拖动悬浮窗 | 按住非按钮区域拖动（非固定模式） |
| 点击图钉 📌 | 固定模式：隐藏按钮、开启鼠标穿透，点击直接透传给下层应用 |
| 悬停窗口 1.5s | 自动解除固定（固定模式下鼠标停留在窗口上即可“唤醒”） |
| `Ctrl+Alt+T` | 解除固定（与悬停等效，双保险） |
| 点击 X | 隐藏悬浮窗，本次全屏周期内不再显示，下次进入全屏重新出现 |
| 退出全屏 | 悬浮窗立即自动隐藏 |
| 托盘右键 → 直接退出 | 彻底退出程序 |
| 再次启动 | 单实例保护，重复启动自动退出 |

> 固定模式的悬停解除：穿透（`WS_EX_TRANSPARENT`）只屏蔽窗口鼠标消息，程序内以 250ms
> 定时器轮询 `GetCursorPos` 检测鼠标是否停留在窗口上（比 `WH_MOUSE_LL` 钩子更轻），
> 停留 1.5 秒自动解除固定；悬停期间窗口浮现实心图钉作为“即将解除”的视觉反馈。

## 技术要点

- **每像素 Alpha 渲染**：D2D/DWrite 绘制到 32bpp ARGB DIB，经 `UpdateLayeredWindow` 提交，
  实现"半透明圆角背景 + 不透明文字"，文字灰度抗锯齿，圆角外区域全透明。
- **自动反色**：每次渲染前 `GetPixel` 采样窗口上沿 5 个点计算背景亮度（<128 视为深色），
  深色背景黑底白字、浅色背景白底黑字，保证任何背景下文字清晰。
- **单行布局**：时间 + 图钉（双状态：空心=未固定 / 实心=悬停解除提示）+ 关闭，渲染目标固定
  96 DPI，布局坐标即物理像素，与鼠标热区一致。
- **全屏检测**：后台线程 1Hz 轮询 `GetForegroundWindow` + `GetWindowRect` 与主显示器矩形比较；
  排除 `WS_MAXIMIZE` 误报（任务栏自动隐藏时最大化窗口同样覆盖全屏）；进入全屏延迟 1.5s 防抖。
- **鼠标穿透**：`SetWindowLongPtrW(GWL_EXSTYLE)` 动态开关 `WS_EX_TRANSPARENT`；
  固定模式悬停 1.5s 自动解除（250ms 定时器轮询 `GetCursorPos`），热键 `Ctrl+Alt+T` 双保险。
- **性能**：静默驻留私有内存约 1.6MB，CPU 占用趋近 0%；渲染器与窗口延迟到首次全屏才创建。
- **DPI**：`SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2)`，多倍率缩放下文字清晰。
- **单实例**：命名 Mutex 保证唯一实例。

## 验证

`scripts/` 下为自动化验证脚本（PowerShell）：

- `verify_basic.ps1`：DLL 依赖、启动、单实例、内存
- `verify_fullscreen.ps1`：全屏检测触发与隐藏
- 调试日志：设置环境变量 `TIMESTICK_LOG=<文件路径>` 后运行，可查看运行轨迹

## 已知限制（PRD 0.1.0）

- 仅检测主显示器全屏；多显示器、应用白名单后续版本支持
- DirectX 独占全屏模式无法在其上叠加渲染（TOPMOST 分层窗口的系统限制）
